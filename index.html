TikTok Price Tool

Lấy giá trong từng trang sản phẩm bằng Chrome trên máy treo của bạn.

Mở giao diện máy treo

Chạy TikTokPricePublic.exe trên máy treo, rồi dán link HTTPS ứng dụng tạo vào đây. Đăng nhập bằng tài khoản admin và mật khẩu bạn đặt trên máy đó.

Tải tool Windows

Cài tiện ích trong thư mục extension vào đúng Chrome muốn dùng. Mở ứng dụng public, giữ Chrome và tab nội bộ hoạt động suốt lúc lấy giá.
